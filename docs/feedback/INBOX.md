- [x]  1. 플랫폼을 전부 원웨이 플랫폼으로 통일  (바퀴 #17, 커밋 5e602a5 — STATUS "레벨 레이아웃" 참고)
		- 기존에 있던 일반(위아래 모두 막힌) 플랫폼은 전부 제거하고, 모든 플랫폼을 원웨이 플랫폼(아래→위는 항상 통과, 위→아래는 평소 막혀있다가 드롭다운 입력 시에만 통과)으로 교체해줘.
		- 배치 재설계:
    - 현재 캐릭터의 점프 파라미터(jumpForce, 중력 등)를 기준으로 한 번의 점프로 도달 가능한 최대 수직 높이를 먼저 계산해줘
    - 그 도달 가능 범위 안에서, 기존보다 플랫폼을 상하로 더 촘촘하게 여러 층으로 배치해줘 (한 번의 점프로 다음 층에 자연스럽게 닿을 수 있는 간격 기준)
    - 플랫폼끼리 물리적으로 겹치거나, 점프 궤적이 플랫폼 모서리에 걸려서 부자연스럽게 충돌하는 위치는 피해서 배치해줘
    - 배치를 마친 뒤, 실제로 캐릭터가 바닥에서부터 점프만으로 모든 층을 순서대로 올라갈 수 있는지, 그리고 각 층에서 드롭다운으로 아래층까지 내려올 수 있는지 직접 확인하고 결과를 알려줘
    - 만약 점프로 닿지 않는 구간이 있다면 그 위치를 알려주고 간격을 조정해줘
